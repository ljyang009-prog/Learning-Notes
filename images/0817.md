## 四、ARM 体系架构

### 1. RISC 与 CISC
| 类型 | 特点 |
|------|------|
| **RISC**（精简指令集） | - 指令系统简单（约 100 条）<br>- 寻址方式少（约 8 种）<br>- 指令格式整齐，执行时间基本一致 → 适合流水线<br>- CPU 与存储器交互通过 Load/Store 指令 |
| **CISC**（复杂指令集） | - 功能由专用指令完成<br>- 指令系统繁杂，寻址方式多样 |

### 2. 体系架构类型
- **冯·诺依曼架构**：指令与数据共用存储
- **哈佛架构**：指令存储与数据存储独立

### 3. 数据类型与存储
- **数据类型**：
  - 字节数据（1 Byte）
  - 半字数据（2 Byte）
  - 字数据（4 Byte）
- **多字节存储方式**：
  - 小端格式
  - 大端格式

## 五、ARM 处理器模式

### 支持的 7 种模式
| 模式 | 说明 |
|------|------|
| 用户模式（usr） | 应用程序运行模式，不可切换至其他模式 |
| 快速中断模式（fiq） | 快速中断响应 |
| 中断模式（irq） | 普通中断响应 |
| 管理模式（svc） | 操作系统保护模式，复位后进入 |
| 中止模式（abt） | 用于虚拟内存和存储保护 |
| 未定义模式（und） | 执行未定义指令时进入 |
| 系统模式（sys） | 特权任务模式，可切换至其他特权模式 |

> **特权模式**：除用户模式外均为特权模式，可自由切换处理器模式。  
> **用户模式与系统模式**：都不能由异常进入，且寄存器组完全相同。

## 六、ARM 寄存器

### 寄存器总数
- **37 个寄存器**：
  - 31 个通用寄存器（32 位）
  - 6 个状态寄存器

### 各模式寄存器分布
| 模式 | 寄存器 |
|------|--------|
| 用户 / 系统 | R0~R15, CPSR |
| 管理模式 | R0~R12, R13_svc, R14_svc, R15, CPSR, SPSR_abt |
| 中止模式 | R0~R12, R13_abt, R14_abt, R15, CPSR, SPSR_abt |
| 未定义模式 | R0~R12, R13_und, R14_und, R15, CPSR, SPSR_und |
| 中断模式 | R0~R12, R13_irq, R14_irq, R15, CPSR, SPSR_irq |
| 快中断模式 | R0~R7, R8_fiq~R14_fiq, R15, CPSR, SPSR_fiq |

### 重要寄存器说明
- **R0~R7**：未分组寄存器，所有模式共用
- **R8~R14**：分组寄存器，不同模式物理上独立
- **R13（SP）**：堆栈指针
- **R14（LR）**：链接寄存器，保存返回地址
- **R15（PC）**：程序计数器，指向当前取指地址

### 状态寄存器
- **CPSR**：当前程序状态寄存器
- **SPSR**：备份状态寄存器

#### CPSR 关键位
| 位域 | 说明 |
|------|------|
| 模式位（0~4） | 设置处理器模式 |
| T 位 | Thumb 模式指示（只读，通过 bx 切换） |
| F 位 | 快速中断禁止位 |
| I 位 | 中断禁止位（1 表示禁止） |
| N 位 | 符号位（负数为 1） |
| Z 位 | 零位（结果为 0 时为 1） |
| C 位 | 进位 / 借位位 |
| V 位 | 溢出标志位（溢出时为 1） |

## 七、Linux 系统定制

### Bootloader 引导程序
- **作用**：在操作系统运行前执行，初始化硬件、建立内存映射，为内核启动准备环境。
- **相当于**：PC 中的 BIOS。
- **硬件初始化流程**：
  1. 关闭指令 / 数据 Cache
  2. 关闭中断
  3. 关闭看门狗
  4. 配置 PLL
  5. 配置内存
  6. 初始化各模式堆栈
  7. 配置中断
  8. 拷贝 RW 段，初始化 ZI 段

> 嵌入式系统加电复位后，CPU 从复位地址取第一条指令。
